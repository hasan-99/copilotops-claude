# Professional Document Design

Apply these design principles to all business documents.

## Document Structure

```
┌─────────────────────────────────────┐
│  HEADER (logo left, doc info right) │
├─────────────────────────────────────┤
│                                     │
│  TITLE BLOCK                        │
│  Document title (24-28pt, bold)     │
│  Subtitle/date (11pt, gray)         │
│                                     │
├─────────────────────────────────────┤
│                                     │
│  BODY CONTENT                       │
│  Sections with clear hierarchy      │
│                                     │
├─────────────────────────────────────┤
│  FOOTER (page numbers, legal text)  │
└─────────────────────────────────────┘
```

## Spacing Rules

| Element | Spacing |
|---------|---------|
| Page margins | 1 inch (2.54cm) all sides |
| After document title | 24pt |
| Before section heading | 18pt |
| After section heading | 6pt |
| Between paragraphs | 12pt |
| Line height | 1.15 - 1.3 |
| Table cell padding | 8pt vertical, 12pt horizontal |

## Typography Hierarchy

| Element | Font | Size | Weight | Color |
|---------|------|------|--------|-------|
| Document title | Sans-serif | 24-28pt | Bold | Primary brand or #1a1a1a |
| Section heading (H1) | Sans-serif | 16pt | Bold | #1a1a1a |
| Subsection (H2) | Sans-serif | 13pt | Semibold | #333333 |
| Body text | Serif or Sans | 11pt | Regular | #333333 |
| Table header | Sans-serif | 10pt | Bold | #1a1a1a |
| Table cell | Sans-serif | 10pt | Regular | #444444 |
| Caption/footer | Sans-serif | 9pt | Regular | #666666 |

**Font recommendations:** Arial, Calibri, Helvetica (sans); Georgia, Cambria (serif)

## Visual Elements

### Tables
- Light gray header background (#f5f5f5)
- 1pt borders in #e0e0e0
- Alternating row colors optional (#fafafa)
- Left-align text, right-align numbers
- No bold in cells except headers

### Horizontal Rules
- Use sparingly (after title block, before signature block)
- 1pt solid #cccccc
- Full width with margin alignment

### Lists
- 18pt left indent
- 6pt between items
- Consistent bullet style (•) or numbering

## Section Organization

Standard order for agreements/contracts:
1. Title + parties identification
2. Recitals/background (if needed)
3. Definitions (if complex)
4. Core terms (numbered sections)
5. Payment/compensation
6. Term and termination
7. Confidentiality
8. Liability/indemnification
9. General provisions
10. Signature block

Standard order for proposals:
1. Cover/title
2. Executive summary
3. Scope of work
4. Deliverables
5. Timeline
6. Investment/pricing
7. Terms and conditions
8. Next steps
9. Signature/acceptance

## Header/Footer Design

**Header:**
- Logo: top-left, max height 40pt
- Document reference: top-right, 9pt gray
- Thin separator line below (optional)

**Footer:**
- Page numbers: centered or right-aligned
- Format: "Page X of Y" or just "X"
- Company name/confidentiality: left side, 8pt gray

## Brand Integration

When brand assets are available:
- Primary color: use for title, accent lines, table headers
- Logo: header placement, maintain aspect ratio
- Secondary color: links, highlights (sparingly)

Without brand assets:
- Use #2563eb (professional blue) as accent
- Default to clean black/gray typography

## Output Checklist

Before finalizing any document:
- [ ] Consistent heading hierarchy throughout
- [ ] No orphan headings (heading at page bottom, content on next page)
- [ ] Tables don't break awkwardly across pages
- [ ] Signature block has adequate space
- [ ] Page numbers present on multi-page docs
- [ ] Margins consistent throughout
- [ ] No excessive white space gaps
- [ ] Professional filename (no spaces, descriptive)
