## Key Decisions Made

- **Supabase as source of truth** - localStorage/IndexedDB are fallbacks, Supabase data always takes priority when available
- **Scripts in separate table** - Script content stored in `scripts` table with foreign key to `projects`, using upsert pattern
- **Moodboard persistence strategy** - localStorage persist added as backup, but `syncFromSupabase()` overwrites on project load
- **RPC functions use SECURITY DEFINER** - Functions check `auth.uid()` internally for proper RLS enforcement
