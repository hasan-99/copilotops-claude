## 🎯 Common Automation Workflows

### Build a Complete SaaS Application
```bash
# 1. Generate the application
Use fullstack-generator to create a T3 stack SaaS

# 2. Setup authentication and database
Use supabase-master to configure auth and database

# 3. Modernize the UI
Use ui-ux-modernizer to create a beautiful interface

# 4. Deploy to production
Use vercel-ai-deploy to deploy with CI/CD
```

### Create an AI-Powered Application
```bash
# 1. Build the AI agent
Use ai-agent-builder to create a LangChain agent

# 2. Create the frontend
Use fullstack-generator for Next.js app

# 3. Integrate APIs
Use api-integrator to connect OpenAI and Stripe

# 4. Deploy
Use vercel-ai-deploy with AI template
```

### Debug Complex Issues
```bash
# 1. Initial debugging
Use universal-debugger to analyze the error

# 2. If database-related
Use supabase-master for database debugging

# 3. If UI-related
Use ui-ux-modernizer to fix UI issues

# 4. Test the fix
Use test-runner to verify the solution
```

### Build a Voice AI Assistant
```bash
# 1. Create VAPI agent
Use vapi-voice-agent to setup voice AI

# 2. Build webhook server
Use api-integrator for webhook handling

# 3. Deploy to production
Use vercel-deploy for server deployment
```

### Adding New Skills
To create your own skill:

1. Create directory: `mkdir ~/.claude/skills/my-skill`
2. Create skill file: `~/.claude/skills/my-skill/SKILL.md`
3. Add frontmatter and instructions
4. Skill is immediately available
